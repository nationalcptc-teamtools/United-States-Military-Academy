# Candidate tooling catalog

Prepared: 2026-10-14. Supports [proposal](proposal.md) and [requirements](spec.md). **Research candidates, not installed tools or an approved competition package.** Forty entries represent 39 upstream projects because LinPEAS and WinPEAS share PEASS-ng. Upstream README/license declarations were inspected; exact releases, dependency licenses, hashes, security posture and actual runtime compatibility remain to be validated before staging.

Farm scenarios below are Analyst inferences about possible assessment needs. They assert nothing about Butter Family Farms. Libraries need small reviewed helpers/runbooks; they are not necessarily ready-made assessment CLIs. Lab systems are for synthetic rehearsal, not for installation in a customer network.

## Selection guide

- **P0:** evaluate for the first small kit; contingent on scope, runtime and license review.
- **P1:** add when its capability or output improves a selected workflow.
- **P2:** specialist option; justify from evidence or a concrete training need.
- **HOLD:** research retained, but a stated license/maintenance issue blocks default staging.
- **LAB:** simulator/server/tooling for an isolated synthetic lab; not an assessment payload.

Operation classes: **O** = offline file analysis; **P** = capture on an authorized interface/TAP/SPAN; **A** = sends traffic, including discovery, reads, handshakes and subscriptions; **H** = executes on a host; **W** = can change device/process/network state; **L** = lab service. Listed classes describe relevant capabilities, not a guarantee about every feature. Installation must not invoke any of them against targets. Active reads can still affect OT availability.

License names below are upstream declarations, not legal certification. A linked project README/license section is the evidence unless a separate license file is linked. Mixed/custom terms need artifact-specific review; the team repository's MIT license cannot replace them. No tool is labeled maintained merely because its repository is public.

## Deliberate holds, exclusions and unresolved coverage

- **Nmap / existing super_nmap.py:** retain awareness of the existing repository workflow. [NPSL terms](https://nmap.org/npsl/) require a specific redistribution decision; do not silently treat Nmap as a standard GPL dependency. The wrapper's aggressive defaults and exit-status handling need separate design/remediation before OT reuse. No Nmap removal is proposed.
- **modpoll:** do not confuse it with GPL mbpoll; the [mbpoll upstream explanation](https://github.com/epsilonrt/mbpoll) distinguishes their code/licenses. It is not in this open-source selection.
- **OpenPLC v3 and legacy editor:** [v3 README](https://github.com/thiagoralves/OpenPLC_v3) states end of life and points to v4; the [old editor](https://github.com/thiagoralves/OpenPLC_Editor) is archived. They are not the default lab baseline.
- **BACpypes3:** license metadata conflict is an observed hold, not an invented certainty. BACnet Stack is the primary alternative to evaluate.
- **pycomm3 and OpenDNP3:** inactive/archived status prevents a routine default recommendation. Record a maintained replacement or a named owner for any narrowly justified fallback.
- **Unsupported protocols:** PROFINET engineering, EtherCAT, vendor-specific wireless links, complete ISO 11783 task-controller/virtual-terminal behavior, proprietary dairy/irrigation interfaces, and vendor engineering suites have no validated dedicated selection here. Wireshark/Scapy may support some analysis, but coverage must be confirmed per release; this list is not universal farm-tool coverage.
- **Commercial/freeware suites, paid services, default credential packs, automated exploitation chains, RF disruption and internet-wide discovery** are outside the initial package. This does not assert the event bans every such product; it reflects this proposal's open-source, evidence-limited preparation scope.

Before staging any selected item: verify the exact version and license, dependencies and artifact hashes; run synthetic/offline checks on the agreed runtime; record side effects and limits; confirm the public acquisition/staging route and eligible maintainer. No version is labeled tested in this catalog.
