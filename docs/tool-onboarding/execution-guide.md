# Execution guide

Root is sole writer. Analyst and reviewer agents return findings without edits. Follow Analyst → Architect → Planner → Developer → Tester → independent Reviewer → Root remediation. Read existing workflow, inventory, profile, maintenance and runbooks before changes. Preserve synced sources, prior remediation and upstream contributor changes.

Only acquisition/build package endpoints are permitted during preparation. Test actual installations only in disposable containers or designated local output paths. Do not contact assessment targets or launch services. Preserve failed-step evidence. Do not claim an untested runtime, hardware workflow or license decision is accepted. Route every finding R-* to root; rerun affected checks after changes. Keep public records portable and synthetic; private local paths and downloaded binaries are not published.
