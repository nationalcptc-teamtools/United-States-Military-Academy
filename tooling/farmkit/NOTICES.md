# Attribution and license boundaries

Team-authored helper/docs/metadata/fixtures use [the module MIT license](LICENSE). This does not relicense or distribute any upstream tool, dependency, data file, trademark, driver or protocol specification. No upstream source/binary/license bundle is included. Catalog descriptions paraphrase public upstream capability/license declarations; evidence is linked per entry. No license interpretation is certified by the helper.

Pinned source evidence was researched read-only on 2026-10-15. [sources.json](sources.json) records the exact release/commit and immutable license/metadata locators for PEASS-ng, Wireshark, PyModbus, mbpoll, python-snap7, cpppo, asyncua, BACnet Stack and Mosquitto. Generated archive locators were not byte-validated, and null digests mean not acquired. Release candidates are from 2026 and do not establish availability at a historical October 2025 event.

Retain PEASS custom GPL v2-or-later language and its stated result-parsing/aggregation interpretation; do not silently label it GPL-3. Preserve its third-party exceptions. Impacket's modified Apache terms, BACpypes3's MIT/BSD metadata conflict and selected Metasploit component/module terms remain held. Inactive pycomm3 and archived OpenDNP3 remain held for maintenance/compatibility ownership. BACnet Stack has core GPL-with-exception plus MIT/Apache files; generate notices for the actual chosen app/core. cpppo has custom GPL/protocol-exception wording and crypto_licensing/greenery dependencies needing review. asyncua metadata specifies LGPL-3.0-or-later. Mosquitto declares EPL-2.0 OR BSD-3-Clause.

Wireshark's official [download page](https://www.wireshark.org/download.html) was used to choose stable 4.6.9, rather than simply choosing the numerically largest tag. A researched v4.6.16 tag had a conflicting 4.4.16 build message; it was not selected. Prefer Linux TShark/offline analysis; Windows installers can include Npcap with separate redistribution terms. [4.6.9 release notes](https://www.wireshark.org/docs/relnotes/wireshark-4.6.9.html) also reinforce that offline parsers need reviewed versions and resource bounds.

OpenPLC Runtime v4's MIT declaration is supported by [its current LICENSE](https://github.com/Autonomy-Logic/openplc-runtime/blob/main/LICENSE). The [legacy v3 repository](https://github.com/thiagoralves/OpenPLC_v3) supports the end-of-life warning only; it is not evidence for v4's license.

Public [CPTC network guidance](https://cp.tc/support/competition-network/) and [October 2025 rulebook](https://cp.tc/docs/cptc-rules.pdf) supply preparation constraints, subject to current event SOW/ROE and official clarification. Neither publicly available tools nor repository access alone authorize targets, staging, publication, outside assistance or physical/radio work.
